Install

An Echo that reaches the internet reads this list itself: on its settings page, Plugins, then "Browse plugins". For one that does not, install from a file:

  1. Download the plugin's .hmp file here.
  2. Open the Echo's settings page (the "Web UI" address in Home Assistant, or http://<the Echo's address>:28931), then Plugins. Switch plugins on if they are off.
  3. Choose "Install from file…" and pick the download. The Echo checks the package itself and shows what the plugin may do, and the author key's fingerprint: it should read as it does here.
  4. Press the Echo's action button to accept. Nothing is installed without it.

This page is not what keeps you safe: it is not signed. The Echo checks every package itself (its author's signature, and the listing by this index's key) and refuses one that does not hold, whatever any page says. An official plugin's update that asks for nothing new installs without the button; anything wider asks again.
